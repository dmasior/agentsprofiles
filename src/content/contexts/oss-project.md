## rules
- Follow CONTRIBUTING.md, repository instructions and local conventions.
- Keep changes focused and easy for maintainers to review.
- Preserve documented interfaces, configuration and user workflows.
- Update docs and release notes for each user-visible change.
- Run relevant tests and repository checks before submitting changes.

## ask-first
- Break compatibility or change project-wide tooling.
