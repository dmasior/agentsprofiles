## rules
- Use semantic HTML and native controls before custom widgets.
- Make every interactive element usable with keyboard and screen reader.
- Keep components small. Keep state close to where it is used.
- Handle loading, empty and error states for each data request.
- Check the layout at mobile and desktop widths.
- Do not add a dependency for a feature that the platform already has.
