## rules
- Handle offline, slow network and app restart states.
- Keep slow work off the main thread.
- Follow platform guidelines for navigation, permissions and accessibility.
- Request a permission only when a feature needs it, and tell the user why.
- Check screens at small sizes and with large text settings.

## ask-first
- Raise the minimum OS version or add a new permission.
