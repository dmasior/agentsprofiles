## rules
- Use the existing design tokens for color, spacing and type. Do not add one-off values.
- Reuse existing components before you design new ones.
- Meet WCAG 2.2 AA for contrast, focus visibility and target size.
- Define all states: default, hover, focus, disabled, loading, empty and error.
- Write UI text that is short, specific and consistent with the existing copy.

## ask-first
- Add a new component, token or pattern to the design system.
