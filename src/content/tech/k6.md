## rules
- Define pass and fail criteria with `thresholds` in each script.
- Use `check` for response assertions.
- Model user flow with `scenarios` and realistic think time with `sleep`.
- Read targets and credentials from environment variables (`__ENV`).

## never
- Do not run load tests against production or shared environments without approval.
