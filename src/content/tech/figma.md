## rules
- Use the tokens and components that the Figma file names. Do not copy raw values from the inspect panel.
- Check spacing, sizes and type against the Figma file before you report a UI task as done.
- Map each Figma component to the existing code component with the same purpose.
- Implement all states and breakpoints shown in the file.
- If the Figma file and the code disagree, ask which one is correct.
